# 출시 노트

## 스토어 등록용 (사용자에게 보이는 글)

> 톤: 해요체. 기술 용어 대신 "무엇이 좋아졌는지"로 씀.
> 앞의 3줄만 읽어도 이번 업데이트가 뭔지 알 수 있게 배치.

### 짧은 버전 (124자 — 노출 공간이 좁을 때)

```
사주가 들어왔어요. 생년월일과 태어난 시간으로 내 사주 원국을 직접 계산해서,
오늘·이번 달·올해·10년 흐름까지 풀어드려요. 가족이나 친구 사주도 추가해서
볼 수 있어요. 매일 다른 운세가 나오도록 문장도 대폭 늘렸어요.
```

### 기본 버전 (445자 — 권장)

```
이번 업데이트로 사주가 앱의 중심이 됐어요.

▪ 내 사주 원국을 직접 계산해요
생년월일과 태어난 시간으로 네 기둥을 세우고, 오행 균형과 타고난 기운을
풀어드려요. 태어난 시간은 진태양시까지 보정해서 계산해요.

▪ 오늘·이번 달·올해·10년 흐름을 봐요
하루 단위 일운부터 10년 단위 대운까지, 지금 나에게 어떤 기운이 흐르는지
단계별로 확인할 수 있어요.

▪ 가족·친구 사주도 볼 수 있어요
이름과 생년월일을 넣으면 그 사람 사주도 함께 볼 수 있어요.

▪ 매일 다른 운세
운세 문장을 크게 늘리고, 최근에 본 문장은 다시 나오지 않게 했어요.

▪ 나에게 잘 맞는 운세를 알려드려요
검증이 쌓이면 어떤 운이 유독 잘 맞는 사람인지 알려드리고, 한 달 검증 기록을
달력으로 볼 수 있어요.

▪ 그 밖에
내 정보 수정·삭제 기능이 생겼어요. 공유는 이제 광고 없이 바로 할 수 있어요.
```

## 내부용 상세 (심사 답변·팀 공유용)

기간: `b623e6e` → `cff494b` (13 커밋)

### 새 기능

| 항목 | 내용 |
|---|---|
| 사주 엔진 | 년/월/일/시주, 지장간, 십성 10종, 십이운성, 신살, 천을귀인, 공망, 형·파·해, 천간 합충, 신강약(득령·득지·득세), 조후, 용신 |
| 시간 단위 운 | 대운(10년) → 세운(1년) → 월운(1달) → 일운(하루). 주 단위는 명리에 없어 제외 |
| 사주 풀이 화면 | 원국 4기둥, 오행 분포, 일간 물상, 신강약, 조후·용신, 십성, 신살, 대운 흐름 |
| 사람 추가 | 이름·생년월일·생시·성별로 추가, 보상형 광고 게이트, 열람 전용(검증은 본인만) |
| 개인화 인사이트 | 카테고리별 5회 이상 쌓이면 "가장 잘 맞는 운세" 노출 |
| 검증 달력 | 한 달 O/X 히트맵 |
| 내 정보 수정·삭제 | 온보딩 이후 수정 경로가 없던 문제 해결 |

### 정확도 개선

- **진태양시 보정** — 서울 기준 −32분. 시지 경계가 정각 → 정각+32분. 분 단위 전수 측정 시 26.7%가 달라짐
- **한국 표준시 이력** — 1954-03-21~1961-08-09 UTC+8:30, 1987·1988 여름 서머타임 UTC+10. 해당 시기 출생자 시주 오류 해소
- **천간충 6쌍 오답 수정** — mod-10 단방향 오프셋이 비대칭이라 경갑·신을·임병·계정을 놓치고 경병·신정을 오탐하던 문제
- **신강약 임계값 교정** — 득령 보너스 폭이 중화 밴드보다 넓어 판정이 사실상 득령 하나로 결정되던 문제. 중화 비율 11.4% → 23.9%
- **조후가 억부를 대체하던 문제** — 재다신약 사주에 재성을 용신이라 답하던 케이스(8.7%) 해소
- **대운 길흉 판정** — 천간만 보던 것을 지지(지장간 본기 포함)까지 반영
- **대운수** — 절입까지의 실제 날수 ÷ 3 (기존엔 순행 3세/역행 7세 근사)

### 사용자 체감 수정

- **운세 문장 반복** — 첫 반복 평균 2.8~4.2일 → 15일. 120일간 서로 다른 문장 28개 → 45개
- **사람 추가 후 검증 불가** — 사람을 추가하면 pin이 되지 않아 밤마다 검증 화면이 비고 연속기록이 끊기던 문제
- **공유 광고 제거** — 광고를 보고 공유해도 얻는 게 없던 구조를 해소
- **광고 실패 시 무반응** — 로드 실패·미시청 시 이유를 안내
- **통계 0% 표시** — 검증 이력이 없을 때 큰 "0%"가 실패로 읽히던 문제 → "–"

### 정직성 관련 수정 (심사 시 설명 필요할 수 있음)

- **지어낸 전국 통계 제거** — 집계가 없을 때 `hitRate: 52+(seed%41)`로 그럴듯한 수치를 만들어 "내 띠는 오늘 전국 N위"로 보여주던 코드를 삭제. 이제 집계가 없으면 안내 문구만 노출
- **표본 필터 추가** — 띠당 10명 미만은 랭킹에서 제외, 5개 띠 미만이면 랭킹 자체를 표시하지 않음
- **허위 문구 삭제** — 스토어 설명의 "공유하면 열려요"는 코드에 해당 경로가 없었음

### 개인정보 고지 변경 (중요)

이번 업데이트로 수집 항목이 늘어 고지를 모두 갱신함. **스토어 등록 정보에도 반드시 반영해야 함.**

- **성별 추가** — 대운 방향(양남음녀 순행) 계산에 필요. 선택 입력
- **제3자 정보** — 사람 추가 기능으로 타인의 이름·생년월일·시간·성별을 수집. 앱 내에 "본인 동의를 받고 입력해 주세요" 문구 추가
- **서버 전송 범위 명확화** — 생년월일은 전송하지 않으나, 검증 결과가 띠·카테고리·O/X 익명 집계로 서버에 저장됨을 명시

현재 문구:
> 생년월일·태어난 시간·성별과 추가한 사람의 정보는 사주 계산에만 쓰이고 이 기기에만
> 저장돼요. 검증 결과는 이름·생년월일 없이 띠 단위 익명 집계로만 서버에 저장돼요.
> 모든 보상은 앱 내 가상 보상이에요.

### 알려진 제약 (의도된 선택)

- **자시 유파** — 야자시설 채택(일주는 KST 자정에 변경). 자시일수설과는 23~24시 출생자의 일간이 다름
- **진태양시 지역** — 서울 고정값. 부산 등은 약 23분으로 차이가 있으나 출생지를 추가로 받지 않음
- **절입일 출생 + 생시 미입력** — 정오로 가정하므로 약 1.4%가 월주 오배정 가능. 생시를 넣으면 해소
- **주(週) 단위 운** — 60갑자에 7일 주기가 없어 제공하지 않음

### 기존 사용자 영향

- localStorage 자동 마이그레이션. 연속기록·검증 이력·적중률 모두 유지됨(실제 브라우저로 검증)
- **00:00~00:31 출생자는 일주가 하루 앞으로 이동** — 진태양시 보정에 따른 정상 결과. 생시를 넣은 사용자의 약 2%
- 생시를 입력하지 않은 사용자는 원국이 바뀌지 않음
